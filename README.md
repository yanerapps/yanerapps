# Yaner Apps

Android apps for testing, monitoring, and everyday journaling.

An independent software studio building small, focused apps with no dark patterns.

## Apps

- **[GPS-Go](https://yanerapps.com/gps-go)** — Simulate locations, follow routes, and test your app from anywhere.
- **[PingDeck](https://yanerapps.com/#apps)** — Monitor hosts, track response times, and get connection alerts. Coming soon to Google Play.
- **[Paperdot](https://yanerapps.com/#apps)** — A daily journal and planner for tasks, events, and notes. Coming soon to Google Play.
