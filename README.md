# yanerapps.com

Single-page brand site for **Yaner Apps**, built with [Astro](https://astro.build). Fully static, zero framework JS — the only client script is a ~20-line scroll-reveal enhancement.

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

## Deploy — Cloudflare Pages

Connect the repo in the Cloudflare dashboard (Workers & Pages → Create → Pages):

| Setting          | Value           |
| ---------------- | --------------- |
| Build command    | `npm run build` |
| Output directory | `dist`          |

Then add the custom domain `yanerapps.com` under the project's **Custom domains** tab.

## Analytics

Cloudflare Web Analytics is wired but disabled. To enable: dashboard → **Web Analytics** → add site → copy the token, then in `src/pages/index.astro` replace `TOKEN_HERE` and uncomment the beacon `<script>`.

## OG image

`public/og.png` is generated by `npm run og` (renders an inline SVG via resvg; fetches Instrument Sans TTF on first run and caches it in `scripts/fonts/`). Re-run only if the wordmark or tagline changes.

## Fonts

Instrument Sans and Newsreader (both variable) are self-hosted via Fontsource — no external font requests at runtime.
