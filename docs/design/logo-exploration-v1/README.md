# Yaner Apps logo exploration · 01

Created 2026-11-02. **Modern seal is the selected identity** and is used by the production favicon and existing footer references through `public/favicon.svg`. **Refined seal is retained as reference only.**

## Design philosophy: Written Flight

The identity connects an ancient written swallow with a small contemporary software studio. The form should retain a sense of authorship: a recognizable signature with enough clarity to live beside practical software. Each curve and interval deserves deliberate attention; decorative complexity should earn its place.

The seal's crown, enclosed body, lateral wings and divided tail are its structural memory. Refined seal preserves that memory with organic curves and mild asymmetry. Modern seal reconstructs it with a compact proportion, repeated curve vocabulary and consistent terminals. Both are newly drawn vector studies, rather than automatic tracing or scaling of the original paths.

Vermilion remains the common color so that shape drives the comparison. White, charcoal and reverse treatments expose the contour without effects. Careful spacing and restrained typography keep the review focused on the mark. Dedicated micro-size drawings have not been created.

## Files

- `comparison.png`: comparison overview with selection labels, wordmark mockups, 16/24/32/48 px samples and dark/reverse treatments.
- `refined-seal.svg`: Refined seal, reference only; organic seal refinement with six named structural paths.
- `modern-seal.svg`: Modern seal, selected; compact geometric seal with named structural paths.
- Matching `.png` files: 768 × 768 transparent previews.

The SVGs use a 128 × 128 coordinate system and a root `color` value. Paths inherit `currentColor`; there are no embedded images or font dependencies. Both use editable centerline strokes with round caps and joins. Stroke outlines can be expanded in a vector editor for production interchange. The production favicon uses the same Modern seal geometry and preserves the existing light/dark colors through CSS.

Wordmark text on the comparison is an Arial placement study, not final custom lettering. The SVG source files contain only the symbol. Small-size samples are direct renders of the main designs, not separately optimized favicon versions. Review the comparison at 100% for the stated pixel sizes.

Validation: both source SVGs render successfully with the project's installed resvg renderer. The updated comparison overview was visually inspected. The production favicon's geometry matches the selected Modern seal source.
